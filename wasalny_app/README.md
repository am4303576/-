# تطبيق "وصلني" لتوصيل الطعام (Wasalny Multi-Restaurant App)

تطبيق أندرويد متكامل متعدد المطاعم مبني باستخدام **Flutter + Firebase**، مخصص للإنتاج الفعلي (Production) بواجهة عربية كاملة (RTL) ويدعم طباعة الفواتير الحرارية على أجهزة **Sunmi (58mm)** ونظام أمان وتحكم صارم بالأدوار.

---

## 📌 الميزات الرئيسية

1. **نظام الأدوار التلقائي الموحد:**
   - **المالك (الأدمن):** حساب مسجل مسبقاً (`am4303576@gmail.com` برمز مبدئي `178jab90`). صلاحية إضافة مطاعم، تعيين نسب العمولات، إدارة المنيو والبانرات العامة.
   - **مدير المطعم والمطبخ:** استقبال الطلبات الحية، تنبيه صوتي مستمر عالي لا يتوقف إلا بعد فتح الطلب، طباعة الفاتورة تلقائياً (مطبخ + زبون)، إدارة الأصناف وتفعيل/تعطيل التوفر، وتصدير التقارير (PDF و Excel والجرد اليومي 58mm).
   - **الكابتن (التوصيل):** استعراض الطلبات الجاهزة، توجيه مباشر عبر Google Maps أو Waze، زر اتصال فوري بالزبون، وتحصيل المبلغ وتأكيد التسليم.
   - **الزبون:** تصفح المطاعم (أسلوب تطبيق طلبات)، سلة المشتريات، تحديد الموقع الدقيق عبر GPS، جدولة الطلبات، الكوبونات، وتتبع مراحل الطلب لحظياً.

2. **الطباعة الحرارية لأجهزة Sunmi (58mm):**
   - طباعة نسخة المطبخ تلقائياً.
   - طباعة نسخة العميل مع رمز QR مباشر لتتبع حالة الطلب.
   - طباعة تقارير الجرد اليومي بضغطة زر.

3. **الأمان و Firebase:**
   - قواعد حماية Firestore Rules تمنع الزبون من التلاعب بحالة الطلب.
   - التحقق الآمن عبر الـ Cloud Functions دون تخزين أي كلمات سر داخل كود التطبيق.
   - إرسال رموز OTP إلى البريد الإلكتروني صالحة لمدة 5 دقائق.

## 🚀 كيفية بناء ملف الـ APK النهائي

### الطريقة الأولى: عبر GitHub Actions (بدون تثبيت أي برامج على جهازك - مجاناً)
1. قم بإنشاء مستودع (Repository) جديد على حسابك في GitHub (عام أو خاص).
2. ارفع مجلد المشروع `wasalny_app` إلى المستودع.
3. توجه إلى تبويب **Actions** في GitHub، وستجد خط سير العمل **"Build Wasalny Release APK"**.
4. بمجرد انتهاء البناء (يستغرق حوالي 3 إلى 5 دقائق)، ستجد ملف **`Wasalny-Release-APK`** جاهزاً للتحميل المباشر بصيغة `.apk` لتثبيته فوراً على الهاتف.

### الطريقة الثانية: البناء محلياً عبر جهازك
إذا كان لديك Flutter و Android SDK مثبتين على جهازك:
```bash
# 1. الدخول لمجلد المشروع
cd wasalny_app

# 2. تحميل الحزم
flutter pub get

# 3. بناء ملف الـ APK
flutter build apk --release
```
ستجد الملف الناتج في المسار:
`build/app/outputs/flutter-apk/app-release.apk`

## ⚙️ إعدادات Firebase السريعة

1. أنشئ مشروعاً جديداً على [Firebase Console](https://console.firebase.google.com/).
2. أضف تطبيق Android باسم الحزمة: `com.wasalny.app`.
3. نزّل ملف `google-services.json` وضعه داخل المجلد:
   `wasalny_app/android/app/google-services.json`
4. فعّل **Authentication** (Anonymous + Email/Password + Google).
5. أنشئ قاعدة بيانات **Firestore** وارفع ملف القواعد `firebase/firestore.rules`.
6. انشر الدوال السحابية:
   ```bash
   cd firebase/functions
   npm install
   firebase deploy --only functions
   ```
